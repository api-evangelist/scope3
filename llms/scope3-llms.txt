## API Reference
- [Emissions Measurement](https://docs.scope3.com/reference/measure-1.md): Calculates the carbon footprint for advertising media
- [Creative emissions](https://docs.scope3.com/reference/creative-1.md): Calculates the carbon footprint of running a creative
- [Country-channel benchmarks](https://docs.scope3.com/reference/benchmarks-1.md): Emissions by percentile per country and channel
- [Upload Data File](https://docs.scope3.com/reference/postdataupload-1.md): Returns the uploaded data file status
- [Get Data File Upload by ID](https://docs.scope3.com/reference/getdatauploadid-1.md): Returns requested data file upload information
- [Get All Organization Segment Information](https://docs.scope3.com/reference/getorganizationsegmentlist-1.md): Returns filtered list of organization segments
- [Get Organization Segment Data by Segment ID](https://docs.scope3.com/reference/getorganizationsegmentdatabysegmentid-1.md): Returns requested data for the segment
- [Get Saved Lists](https://docs.scope3.com/reference/getsavedlists.md): Returns all property lists available for the authenticated customer, including list ID, name, and domain count.
- [Get Signals by Saved List](https://docs.scope3.com/reference/getsignalsbysavedlist.md): Returns paginated domain-level media quality signals for all domains in the specified saved property list.
